# train-math

小学生向けの「算数 × 電車」ブラウザゲームです。

問題に正解すると横浜線205系風の電車が発車し、駅を進んでいきます。角度・折れ線グラフ・分数・かけ算などの問題に加え、ドア開閉、速度計、駅ごとの乗換車両、発車メロディーなど、電車好きが楽しめる演出を組み込んでいます。

## 遊び方

GitHub Pages の公開URLをブラウザで開くだけです。外部サービスや外部ライブラリは不要で、HTML / CSS / JavaScript / Web Audio API と同梱の音声ファイルで動作します。

## 現在の主な機能

- 横浜線205系風の10両編成
- ステンレス車体の反射、窓の映り込み、台車や車輪の立体感を加えた車両表現
- 問題正解で発車、次駅へ進行
- 角度、折れ線グラフ、分数、かけ算、ミックス問題
- 3段階の難易度切替
- ドアの時間差閉扉、空気音、戸当たり音
- 発車時の加速表現と速度計
- 到着・発車中の移動量に連動する車輪回転
- 添付された音声ファイルによる駅への接近放送・発車放送
- 発車ベルの後に再生する、JRE-IKST-017の発車メロディー音源（2種類）
- 東神奈川・菊名・新横浜・八王子などの駅別背景演出
- iPad / Edgeなどタッチ環境を想定したUI

```text

├─ styles-1.css        # 基本UI・車両・問題画面
├─ styles-2.css        # ドアカメラ・科目/難易度UI
├─ styles-3.css        # 駅別背景・ドア同期
├─ styles-4.css        # 戸当たり・速度計・分数UI
├─ app-1.js            # 基本状態・音・ドア制御
├─ app-2.js            # 旧メロディーの合成関数
├─ app-3.js            # 旧メロディーの合成関数
├─ app-4.js            # 問題生成・描画
├─ app-5.js            # 駅進行・発車処理
├─ app-6.js            # UIイベント・リセット
├─ app-7.js            # 三角定規問題・かけ算・ドア演出
├─ audio/
│  ├─ approach-announcement.mp3  # 接近放送
│  ├─ departure-announcement.mp3 # 発車放送
│  ├─ JRE-IKST-017-01.wav        # 発車メロディー音源1
│  └─ JRE-IKST-017-02.wav        # 発車メロディー音源2
├─ readme.md           # このファイル
├─ ARCHITECTURE.md     # 構造・主要関数・変更時の注意点
├─ DESIGN.md           # 設計思想・プロダクト方針
└─ CHANGELOG.md        # 主な変更履歴
```

元の最新版は1ファイル完結のHTMLでしたが、GitHub上では保守しやすいように、ビルド工程や外部依存を増やさず静的ファイルへ分割しています。GitHub Pagesではそのまま配信できます。

## メンテナンス方針

子どもがすぐ遊べることを最優先にし、フレームワークやビルド工程は追加しません。接近放送・発車放送はリポジトリに同梱した音声ファイルを再生します。更新時は機能追加だけで終わらせず、既存機能の回帰確認とJavaScript構文チェックも行います。

## ライセンス / 注意

発車メロディー音源：JRE-IKST-017（JRE-IKSTシリーズ再現集／フリー素材）。ゲーム画面にもクレジットを表示しています。

車両・駅などの表現は、鉄道を題材にした学習用の独自表現です。

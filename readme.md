# train-math

小学生向けの「算数 × 電車」ブラウザゲームです。

問題に正解すると横浜線205系風の電車が発車し、駅を進んでいきます。角度・折れ線グラフ・分数などの問題に加え、ドア開閉、速度計、駅ごとの乗換車両、発車メロディ風のオリジナル音源など、電車好きが楽しめる演出を組み込んでいます。

## 遊び方

GitHub Pages の公開URLをブラウザで開くだけです。外部ライブラリや外部音源は使わず、HTML / CSS / JavaScript / Web Audio API のみで動作します。

## 現在の主な機能

- 横浜線205系風の10両編成
- 問題正解で発車、次駅へ進行
- 角度、折れ線グラフ、分数、ミックス問題
- 3段階の難易度切替
- ドアの時間差閉扉、空気音、戸当たり音
- 発車時の加速表現と速度計
- 東神奈川・菊名・新横浜・八王子などの駅別背景演出
- 3種類のオリジナル発車メロディ
- iPad / Edgeなどタッチ環境を想定したUI

## ファイル構成

```text
/
├─ index.html          # 画面構造と静的マークアップ
├─ styles-1.css        # 基本UI・車両・問題画面
├─ styles-2.css        # ドアカメラ・科目/難易度UI
├─ styles-3.css        # 駅別背景・ドア同期
├─ styles-4.css        # 戸当たり・速度計・分数UI
├─ app-1.js            # 基本状態・音・ドア制御
├─ app-2.js            # 発車メロディ1/2
├─ app-3.js            # 発車メロディ3
├─ app-4.js            # 問題生成・描画
├─ app-5.js            # 駅進行・発車処理
├─ app-6.js            # UIイベント・リセット
├─ readme.md           # このファイル
├─ ARCHITECTURE.md     # 構造・主要関数・変更時の注意点
├─ DESIGN.md           # 設計思想・プロダクト方針
└─ CHANGELOG.md        # 主な変更履歴
```

元の最新版は1ファイル完結のHTMLでしたが、GitHub上では保守しやすいように、ビルド工程や外部依存を増やさず静的ファイルへ分割しています。GitHub Pagesではそのまま配信できます。

## メンテナンス方針

子どもがすぐ遊べることを最優先にし、フレームワークやビルド工程は追加しません。更新時は機能追加だけで終わらせず、既存機能の回帰確認とJavaScript構文チェックも行います。

## ライセンス / 注意

このゲーム内の車両・駅・発車メロディは、鉄道を題材にした学習用の独自表現です。実在する発車メロディについては原曲そのものを収録・複製せず、雰囲気を参考にしたオリジナル旋律を使用します。
